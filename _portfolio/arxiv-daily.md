I maintain a daily arXiv reading website based on the open-source [daily-arXiv-ai-enhanced](https://github.com/dw-dengwei/daily-arXiv-ai-enhanced) project.

The site combines scheduled paper collection, AI-assisted summaries, and a browser interface for reviewing the literature. GitHub Actions runs the update workflow, and GitHub Pages hosts the website.
